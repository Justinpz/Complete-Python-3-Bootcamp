# ReRack — Typography Rules

> **QUICK REFERENCE**
> - **Display/Headline:** Industrial grotesque, condensed, uppercase (e.g. a Helvetica-Now-Display / Akzidenz / military-stencil-adjacent grotesque). Tight tracking, heavy weight.
> - **Body/Caption:** Clean neutral grotesque, sentence case, generous line height.
> - **Tagline lockup:** `FORGED DAILY.` — uppercase, wide tracking, terminal period, always.
> - **Rule:** Type is structural, not decorative. Left-aligned or centered. Never script, never serif, never outlined.

---

## 1. Type Roles

| Role | Style | Case | Use |
|---|---|---|---|
| Display | Condensed industrial grotesque, heavy/black weight | UPPERCASE | Standalone statements, Reel end-cards, drop headlines |
| Headline | Grotesque, medium-bold | UPPERCASE or Title | Post overlay one-liners |
| Body | Neutral grotesque, regular | Sentence case | Caption copy, descriptions |
| Tagline | Display grotesque, wide tracking | UPPERCASE | `FORGED DAILY.` stamp only |
| Label / micro | Mono or grotesque, light | UPPERCASE | SKU codes, dates, `CYCLE 001`, countdowns |

## 2. Hierarchy & Sizing (on-image overlay, 1080×1350 feed frame)

- **Hero statement:** 90–140px, single idea, max 6 words per line, 1–3 lines.
- **Supporting line:** 32–48px, one supporting clause.
- **Brand stamp / tagline:** 24–32px, wide tracking, bottom-anchored.
- **Micro-label (date/SKU):** 16–20px, mono, corner-anchored.

Maintain a clear 1 → 2 → 3 size jump between levels. No two levels should look similar.

## 3. Tracking & Spacing

- **Display uppercase:** tight to neutral tracking (-1% to 0). Let the weight do the work.
- **Tagline / labels:** wide tracking (+8% to +15%) for a stamped, engineered feel.
- **Line height:** display 95–105%; body 135–150%.
- **Margins:** keep all type inside a safe margin of ≥8% of frame on every edge. Never let type touch an edge.

## 4. Layout Rules

- Left-aligned or centered only. Never right-aligned, never justified.
- Anchor type to a grid edge or true center — never float arbitrarily.
- Reserve generous negative space. The Standard posts are ~70% empty.
- One type cluster per image. Do not scatter text across multiple zones.

## 5. Forbidden

❌ Serifs · ❌ Script / handwriting · ❌ Outlined or hollow type · ❌ Drop shadows / bevels / glows · ❌ Gradient fills · ❌ Italics for emphasis · ❌ More than two type sizes in one cluster · ❌ Emojis in graphics · ❌ Stretched or condensed-by-scaling type (use a true condensed cut).

## 6. Font Direction (sourcing note)

Target an industrial neo-grotesque system. Acceptable directions: Helvetica Now Display, Akzidenz-Grotesk, Suisse Int'l, Aktiv Grotesk, or a clean military-spec stencil for accents only. Pair **one** display cut + **one** neutral text cut + **one** mono for labels. Lock the system and never improvise per-post.
