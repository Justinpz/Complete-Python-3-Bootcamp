# ReRack — Performance Log

> **PURPOSE:** Engagement data + learnings. What worked, what didn't, and why. This is where the system gets smarter over time. `performance-analyzer.py` reads the data table; the Learnings section is for human judgment.
>
> **HOW TO USE:** After a post matures (~48–72h), record its metrics. Weekly, write a short learnings note. Monthly, distill the top patterns into the system.

---

## Metrics convention

- **Eng. Rate** = (likes + comments + saves + shares) / reach, as a %.
- **Saves** and **Shares** are weighted highest — they signal identity resonance, the ReRack goal.
- Track per pillar so we learn which pillar drives which outcome (Standard → saves/shares; Uniform/Drop → profile visits/link clicks).
