## Pairing Notes

Keep a week of Object posts varied across detail type, colorway, and scale:

- **Branding-mark set (space these apart):** `OBJ-01` (black logo), `OBJ-07` (bone logo), `OBJ-15` (back-hit) — same mark across registers; rotate, never adjacent.
- **Construction-detail family:** `OBJ-05` (drop-shoulder), `OBJ-06` (hem/side-seam), `OBJ-10` (collar), `OBJ-12` (stitch) — sequence these across a "how it's made" week; each reveals a different engineered detail.
- **Fabric/colorway-texture set:** `OBJ-02` (black weave), `OBJ-03` (charcoal mottle), `OBJ-11` (olive), `OBJ-14` (tan) — colorway-introduction macros; pair each with the matching `UNI` colorway hero the prior or following day.
- **Product-as-artifact / composition set:** `OBJ-08` (stack), `OBJ-09` (hanging), `OBJ-13` (on concrete), `OBJ-16` (two-tone edge) — wider, more "presented" object shots; use one to anchor a Drop tease.
- **Cross-pillar handoffs:** `OBJ-05`/`OBJ-06`/`OBJ-10` flow directly out of `UNI-05`/`UNI-13` (garment-on-body) — schedule the macro the day after the body hero for a zoom-in effect. `OBJ-04` (woven label) and `OBJ-15` pair with `STD-07` (product-whisper) for craft-trust storytelling.
- **Pillar rule:** never post Object and Uniform back-to-back — punctuate product macros with a Standard between them. Object also feeds Drop lockups: `OBJ-09` and `OBJ-08` are clean canvases for `DRP` type overlays.
